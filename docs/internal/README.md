# Internal maintainer journals

`docs/internal/` holds **maintainer-only** notes: session handoffs, ops runbooks, and other journals that are useful for substrate development but not part of the public contributor path.

| Audience | Start here |
|----------|------------|
| **Contributors & external agents** | [SKILLS.md](../../SKILLS.md), [docs/skills/](../skills/), [AGENT_MEMORY_CONTRACT.md](../AGENT_MEMORY_CONTRACT.md) |
| **Maintainers** | Files in this directory (e.g. [MAINTAINER_WORKFLOW.md](MAINTAINER_WORKFLOW.md), [real_usage_testing_guide.md](real_usage_testing_guide.md)) |

These documents may reference stale PIDs, branch names, or one-off incidents. They are **not** kept in sync with every release. For operational contracts agents should follow, use [HARNESS_INJECTION.md](../HARNESS_INJECTION.md) and [DEFORMATION_PLAYBOOKS.md](../DEFORMATION_PLAYBOOKS.md).
